# CuidarSaude

Protótipo comercial de gestão de clínicas e agendamento. Todos os pacientes e pagamentos são fictícios e ficam no navegador.

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

- `/` apresentação
- `/demo` roteiro da demonstração
- `/desktop` painel da clínica
- `/mobile` aplicativo do paciente
